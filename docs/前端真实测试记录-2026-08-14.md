## Flash 强制配置

当前运行配置：

```text
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_PLANNER_MODEL=deepseek-v4-flash
DEEPSEEK_ANSWER_MODEL=deepseek-v4-flash
DEEPSEEK_THINKING_MODE=disabled
```

Planner 与回答两条调用均显式传入 `thinking.type=disabled`。真实 API 调用返回模型为 `deepseek-v4-flash`，此前的 `HTTP 402` 已不再构成当前阻塞。
