# V1.3 更新说明

版本：`v1.3.0`

这一版继续围绕单公司年报问答，补齐连续年度材料，完善复合问题的召回和答案输出。运行方式沿用 V1，仍使用 BGE-M3、Qdrant Local 和 DeepSeek。

## 数据

- Apple：2022、2023、2024 三份独立年报。
- Microsoft：2021、2022、2023 三份独立年报。
- TCS：FY2021—FY2024 四份独立年报，以及原有 DOCX、XLSX 分析材料。
- 共 12 个来源、6266 个切块，使用同一个活动向量集合。原始文件及来源见 [数据来源](../data/SOURCES.md)。

## 检索与回答

- 原始问题与 Planner 拆分的子问题共同召回，Dense 与 BM25 并行执行，通过 RRF 合并。
- 公司和文档范围统一过滤，增加标识保护、相似内容去重和条件语义重排；重排失败时使用已有候选顺序。
- 多年分部问题补充同份年报的可比表格，保留年份、单位和重列口径信息。
- 覆盖检查默认记录诊断，便于定位子问题证据缺失。`generate=false, plan_retrieval=true` 可单独验证规划与检索；仍可能调用规划及重排模型。
- 答案采用单次生成，支持表格、计算和综合分析。引用校验保留；数值检查只记录诊断，不自动修改或删减回答。
- 请求过程记录在本地 `data/query_logs/`，便于核查检索、证据与生成状态。

## 测试结果

| 测试 | 结果 | 范围 |
| --- | --- | --- |
| 离线回归 | 全量 115 项通过，其中核心模块 98 项 | 检索、API、计算诊断、覆盖检查及复合问题回归 |
| 实际 API 检索 | 12 题 × 2 次，24/24 Hit@5；MRR@10 0.833 | Apple、Microsoft、TCS 小样本固定题集 |
| 复合检索 | Apple 15 项、Microsoft 18 项原始输入均召回 | 同时检查一次性税费、财年周数、使用寿命变更及 Azure 增速证据 |
| 微软复合回答 | 52.64 秒，18 项分部原始值及各分析章节完整返回 | 单次生成；并非全部数值与推理通过 |

检索记录见 [API 检索结果](../data/evaluation/hybrid_api_acceptance.json) 和 [复合检索结果](../data/evaluation/compound_retrieval_acceptance.json)。复合问题见 [压力测试题目](V2复合问题压力测试.md)，实测答案见 [微软三年分析](../data/evaluation/compound_live_2.md)。

微软实测中，PBP 和 Intelligent Cloud 收入 CAGR 写成 13.36%、21.33%，按输入复算应为 13.35%、21.32%；另有金额换算的自我纠正句。检索命中、引用有效和答案完整不等于计算及推理全部正确。当前版本继续保持单用户、本地最小流程，不包含租户权限或外部系统定期对账。
